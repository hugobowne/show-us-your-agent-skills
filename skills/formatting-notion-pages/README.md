# formatting-notion-pages

A Notion formatting skill that augments the Notion MCP with Matt Palmer's preferences for page structure, callouts, toggles, tables, and color.

## who showed it

Matt Palmer leads developer experience at Conductor. He showed this skill while explaining how he keeps a private, portable skill library and installs only the skills he wants into each project.

## what it does

Matt uses Notion heavily, and this skill sits above the Notion MCP as a reference layer for the agent. The MCP gives the agent access to Notion; the skill tells the agent how Matt wants Notion pages formatted.

> *"what this is is basically an augmentation of the Notion MCP, because I use Notion a lot."* [\[01:41:31\]](https://youtube.com/live/6zju7hyCFl0?t=6091)

The skill encodes formatting preferences that are easy for a human to have and easy for an agent to miss: callouts, toggle headings, tables, and color choices.

> *"It just describes basically how I like to format Notion pages."* [\[01:41:45\]](https://youtube.com/live/6zju7hyCFl0?t=6105)

## why it's notable

This is a clean example of a skill as taste over a tool server. The tool server can perform the operation, but the skill carries the user's formatting standards so the output matches the way they actually work.

> *"I found this to be a nice little skill to like accent the actual like notion MCP server if you're using it through codecs or something with the colors that I like."* [\[01:42:02\]](https://youtube.com/live/6zju7hyCFl0?t=6122)
